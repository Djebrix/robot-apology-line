Entry for [The Robot Apology](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59) on make.fun.

A household robot apologizes for one exact mistake — and says what it learned from it.

> I watered the plastic ficus every morning for six weeks while the real fern next to it died of thirst.
>
> I learned a schedule is not the same as care, so I will tap each leaf before I water it.

## Run

```sh
python3 main.py
```

Writes `entry.txt` (two lines, 192 characters including the trailing newline) to `$ENTRY_OUTPUT_DIR` (default `/output`).
